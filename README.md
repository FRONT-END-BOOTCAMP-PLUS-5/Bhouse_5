# 보드게임 하우스 (Boardgame House)

보드게임을 사랑하는 사람들을 위한 **보드게임 정보·매장 탐색·커뮤니티** 서비스입니다.

---

## 서비스 소개

**보드게임 하우스**는 다음을 제공합니다.

- **보드게임 탐색**: 인기 보드게임 목록·상세 정보 조회
- **매장/카페 정보**: 보드게임을 즐길 수 있는 매장·카페 검색 및 상세 정보
- **커뮤니티**: 게시글 작성·조회·댓글 등 소통 공간
- **회원 기능**: 로그인/회원가입, 소셜 로그인, 비밀번호 찾기, 마이페이지, 활동 내역, 알림·키워드·좋아요 등

---

## 기술 스택

- **프레임워크**: Next.js 15 (App Router), React 19
- **스타일**: Tailwind CSS, CSS Modules
- **상태**: React Query (서버 상태), Zustand (전역 상태)
- **폼/검증**: React Hook Form, Zod
- **인증/DB**: Supabase, JWT(jose), bcrypt
- **기타**: Axios, Quill(에디터), ESLint, Prettier, Husky

## 프로젝트 구조

```
app/
├── (anon)/                 # 비로그인 접근 가능 라우트
│   ├── auth/               # 로그인, 회원가입, 비밀번호 찾기, SSO
│   ├── boardgames/         # 보드게임 목록
│   ├── boardgame-detail/   # 보드게임 상세
│   ├── community/          # 커뮤니티 게시글
│   ├── home/               # 홈
│   ├── my/                 # 마이페이지
│   ├── search-result/      # 검색 결과
│   ├── store-info/         # 매장 정보
│   ├── store-register/     # 매장 등록
│   ├── support/            # 고객지원
│   └── user/               # 활동, 설정, 동네 등록
├── _components/            # 공통 컴포넌트 (Header, Footer, Post, Alarm 등)
├── _hooks/                 # 공통 훅
├── api/                    # API 라우트 (boardgames, community, user, auth 등)
└── layout.tsx
```

## 핵심 기술

| 영역                | 현재 구현                                                                           | 목표 기술                                                                                                                                              | 담당 |
| ------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- |
| **검색·자동완성**   | 보드게임명 `ilike` 부분 일치 + 클라이언트 필터, 드롭다운 자동완성 UI                | **퍼지/유사어 검색**: 오타·비슷한 입력도 검색 (예: Levenshtein, n-gram 또는 검색엔진 연동). 보드게임 자동완성 UX 고도화                                | 동규 |
| **로그인·회원가입** | 이메일 로그인/회원가입, 비밀번호 찾기, 약관·회원유형 플로우, JWT·bcrypt             | **기능·디자인 정교화**: 유효성 검사·에러 처리·접근성·반응형 포함, 일반 로그인/회원가입 플로우를 서비스 수준으로 마무리 (소셜 제외)                     | 채영 |
| **알림**            | React Query로 알림 목록 조회, 헤더 벨 아이콘 + 미읽음 개수 뱃지, 읽음/미읽음 스타일 | **실시간 알림 + 일시적 노출**: 실시간 푸시/폴링으로 신규 알림 반영, 상단 뱃지 유지, 알림 도착 시 토스트 등으로 “뿅” 노출 후 일정 시간 지나면 자동 제거 | 채원 |
| **SSO·댓글 실시간** | 카카오/구글 OAuth 연동, 댓글 CRUD + 작성 시 `invalidateQueries`로 목록 갱신         | **SSO 안정화** + **댓글 실시간 갱신**: SSO 콜백·에러 처리 보완, 새로고침 없이 새 댓글 반영 (폴링 `refetchInterval` 또는 WebSocket/SSE 등)              | 다영 |
